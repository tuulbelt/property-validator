# Phase 2 v0.7.5 Results: Eliminate Fast API Result Allocation

**Date:** 2026-01-04
**Optimization:** Changed from `validateFast(itemValidator, data[i]).ok` to `itemValidator.validate(data[i])` in `compileArrayValidator()` (line 873)

## Implementation Details

The Phase 2 optimization eliminates Result object allocation in array validation hot loops:

**Before (Phase 1):**
```typescript
return (data: unknown[]): boolean => {
  for (let i = 0; i < data.length; i++) {
    if (!validateFast(itemValidator, data[i]).ok) return false;
  }
  return true;
};
```

**After (Phase 2):**
```typescript
return (data: unknown[]): boolean => {
  for (let i = 0; i < data.length; i++) {
    if (!itemValidator.validate(data[i])) return false;
  }
  return true;
};
```

**Why this works:**
- `validateFast()` returns `{ ok: boolean, value?: T, error?: ValidationError }` - allocates object on every call
- `validator.validate()` returns `boolean` directly - no allocation
- For arrays with N items, this eliminates N object allocations per validation
